# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

The RitualDev Lab team takes the security of autonomous agent infrastructure seriously. If you discover a security vulnerability in SkillPrism (such as tool description prompt injection, receipt vault exposure, or sandbox escapes):

1. **Do not create a public issue.**
2. Send a detailed report to **security@ritualdev.in**.
3. Include reproduction steps, example inputs, and the impacted environment.

We commit to acknowledging your report within 48 hours and providing a remediation timeline before public disclosure.
