# Accessibility Statement for SkillPrism

RitualDev-Lab is committed to ensuring full digital accessibility for all developers and users, adhering to **WCAG 2.1 Level AA** guidelines.

## Accessibility Features
- **Keyboard Navigation**: Interfaces and CLI workflows are operable via keyboard alone.
- **Color Contrast**: Compliant contrast ratios (>4.5:1 for standard text) across dark and light themes.
- **Screen Reader Support**: Semantic markup and ARIA descriptions for assistive technologies.
- **Clarity**: Descriptive error messages and status feedback.

## Accessibility Inquiries
If you encounter any accessibility issues, please contact us at **accessibility@ritualdev.in**. We aim to respond within 2 business days.
