How SkillPrism Works

The 4-stage lifecycle eliminating context bloat and hallucinated parameters.

1

Out-of-Context Indexing

All 500+ MCP tools and OpenAPI schemas are ingested into an ultra-fast local Okapi BM25 engine. The LLM prompt starts with 0 tools loaded, saving up to 25,000 upfront tokens.

2

The JIT Meta-Tool Harness

The model receives only 2 meta-tools: search_skills and load_skill. When the agent searches for "postgres query", it receives only 1-line tool candidates.

3

Ephemeral Schema Injection

When load_skill is called, the transparent MCP protocol interceptor injects the selected tool's schema into the model's active toolset for that specific step with automated turn TTL expiry.

4

Semantic Receipts & Drill-Down

Heavy tool outputs are vaulted out-of-context and replaced with lightweight Semantic Receipts. The model uses inspect_receipt to query specific fields without loading thousands of lines of JSON.
